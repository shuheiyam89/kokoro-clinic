## 2. 新しく必要な画像（これが揃えば全面リスタイルできる）

### 作り方の共通ルール
- ChatGPT の画像サイズは 1536×1024（横長）／1024×1536（縦長）／1024×1024 のどれか。下の「推奨サイズ」はこの中から指定
- **表情シートは、同じ大きさ・同じ位置・同じポーズで表情だけを変える**。キャラどうしは十分に離す（切り分けのため）
- **透過**と書いたものは、背景を完全な透明にする（白い背景や市松模様の絵は不可）。影・文字・番号・枠線は入れない
- 背景・1枚絵は 3:2 で作り、こちらで中央を 4:3 に切り抜く → **大事なものは中央の4:3（左右の端 約12%ずつは切れる）に収める**
- 同じキャラは、同じチャットで続けて作る（絵柄と見た目がそろう）。参照画像 docs/style-reference.jpg を毎回添付

## 4. 差し替えるときのコード側の変更点（概要）

画像のファイル名は今と同じにそろえるので、ゲームの仕組み（js/story.js・engine.js・data）は変えずに済みます。変えるのは次の所です。

1. **tools/make-art.py（絵の取り込み）**
   - 水彩のふちのにじみが消えないよう、半透明を消すしきい値（今は24）を下げる
   - まばたきは「目の位置を塗る」方式をやめ、*_blink.png のシートから切り出す
   - 背景・1枚絵は 3:2 → 中央 4:3 に切り抜いて 960×720 に
   - 前景（room_front）は、新しい背景のソファの位置に合わせて切り出し範囲を変える（または、リュミエの絵で必要なければ廃止）
   - 体から離れた「！」などを消す処理は、キラキラまで消さないよう調整
2. **js/pixel.js（描画）**
   - 各キャラの座る位置（CHARS の bottom）と大きさ、となりの人（COMP の x・bottom）を新しい絵に合わせて調整
